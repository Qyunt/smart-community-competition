# 智慧社区复赛项目个人归档

本仓库保存我参与 close_ai 队智慧社区复赛期间的工程代码、答辩展示、技术方案、演示视频和相关赛事资料。复赛已经结束，这里作为个人项目经历和学习记录留存。

项目对应第八届全球校园人工智能算法精英大赛算法应用赛道“智慧社区”赛题，涉及 ROS / Gazebo 社区巡检仿真、场景与路线设计，以及人物、车牌和红绿灯识别等内容。

## 版本与复现

复赛提交版本以下载页中的 **2026-10-14 工程 ZIP** 为准；根目录 `src/` 保留 2026-10-10 的历史开发快照。不同日期的工程和工作记录分别保存，便于回顾项目的演进过程。

归档环境为 Ubuntu 18.04、ROS Melodic、Gazebo 9。复现时参考工程 ZIP 内的 README、依赖配置和运行说明。历史记录中的进度、待办和验收结论对应其撰写时的版本。

项目包含团队协作成果和第三方组件，原有署名、来源说明及许可证随资料保留。
